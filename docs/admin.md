# Админка (`admin/`)

Отдельный одностраничный клиент на React, TypeScript и Vite для `console.familytasks.ru`. Раздел «Сервис» показывает статистику аккаунтов, семей и сообщений, очередь писем и push, SMS, планировщик, realtime и состояние хранилища фото. Раздел «Аккаунты» даёт постраничный список участников с поиском, карточку профиля и активности, блокировку и удаление.

Вход использует существующие `POST /api/email-codes`, `POST /api/auth/login`, `GET /api/me` и `GET /api/admin/*`. Администратор входит email-кодом; если сервер включает SmartCaptcha, клиент получает одноразовый токен капчи перед отправкой письма. Токен сессии хранится в `localStorage` этого поддомена и отзывается через `DELETE /api/session` при выходе. `/api/me` возвращает `isAdmin`, а каждый административный маршрут независимо проверяет права на сервере. Сводка сервиса опрашивается раз в 30 секунд.

В списке аккаунтов строки соответствуют участникам, включая участников без семьи. Поиск ищет по имени, email, телефону, коду и фамилии семьи; выдача по 25 записей. Карточка показывает профиль, согласие, семейные связи, сессии, push-подписки и агрегированные счётчики заданий, сообщений, событий, целей, игр и монет.

Блокировка помечает профиль `members.blocked_at`, отзывает активные сессии и закрывает WebSocket-соединения. Совпадающий email или телефон блокирует вход во все профили с этим контактом, в том числе в других семьях; разблокировка одного профиля снимает запрет, если совпадающие профили не заблокированы отдельно. Авторизация и запрос кодов входа проверяют блокировку на сервере. Новая миграция `1760000048000_admin_accounts.sql`.

Удаление обычного участника стирает связанные семейные данные и удаляет файлы из media-хранилища. Удаление участника без семьи стирает профиль и его сессии. Удаление создателя ставит всю семью в очередь `family_deletions` (как самостоятельный маршрут удаления семьи); доступ к этой семье закрывается сразу, фактическое удаление данных и файлов выполняет планировщик.

Локально: `npm run dev:admin` из корня (сервер API должен работать на `localhost:3000`), или `cd admin && npm run dev`. Для отдельной сборки: `cd admin && npm run build`.

Docker Compose собирает отдельный сервис `admin`. В проде Caddyfile обслуживает `console.familytasks.ru`; настройте для него DNS A-запись на адрес сервера. API остаётся на текущем сервере, без отдельного backend.
