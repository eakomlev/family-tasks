# Админка (`admin/`)

Отдельный одностраничный клиент на React, TypeScript и Vite для `console.familytasks.ru`. Сейчас он показывает содержание вкладки «Сервис»: статистику аккаунтов, семей и сообщений, очередь писем и push, SMS, планировщик, realtime и состояние хранилища фото.

Вход использует существующие `POST /api/email-codes`, `POST /api/auth/login`, `GET /api/me` и `GET /api/admin/*`. Администратор входит email-кодом; если сервер включает SmartCaptcha, клиент получает одноразовый токен капчи перед отправкой письма. Токен сессии хранится в `localStorage` этого поддомена и отзывается через `DELETE /api/session` при выходе. `/api/me` возвращает `isAdmin`, а каждый административный маршрут независимо проверяет права на сервере. Клиент опрашивает данные раз в 30 секунд.

Локально: `npm run dev:admin` из корня (сервер API должен работать на `localhost:3000`), или `cd admin && npm run dev`. Для отдельной сборки: `cd admin && npm run build`.

Docker Compose собирает отдельный сервис `admin`. В проде Caddyfile обслуживает `console.familytasks.ru`; настройте для него DNS A-запись на адрес сервера. API остаётся на текущем сервере, без отдельного backend.
